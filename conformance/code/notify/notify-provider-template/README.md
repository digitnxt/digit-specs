# notify-provider-template

A starter template for building a new notification provider plugin for [notify-service](../README.md).

## What's in this repo

| Path | What it is |
|---|---|
| `src/` | Blank provider template — copy this, fill in the TODOs |
| `BUILDING_A_PROVIDER.md` | Step-by-step guide to build and deploy a provider |
| [`notify-provider-examples/`](../notify-provider-examples/) | Working reference implementations (email, sms, whatsapp) |

## Quick start

Read [BUILDING_A_PROVIDER.md](BUILDING_A_PROVIDER.md).

## Prerequisites

| Tool | Version |
|---|---|
| Java | 25 |
| Maven | 3.9+ |
| notify-service | running instance |
